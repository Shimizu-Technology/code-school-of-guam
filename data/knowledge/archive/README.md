# Archived knowledge files

These files are historical. They are not part of the chatbot's reviewed source bundle and must not be embedded or presented as current offers. Several describe the closed March 2026 bootcamp (for example its $7,500 tuition and original schedule) or older policies.

The active sources are listed in `lib/active-knowledge.ts` (`ACTIVE_KNOWLEDGE_FILES`) and live in `data/knowledge/`. Moving a file back into the active bundle is a knowledge source edit: it requires review, a new immutable `ACTIVE_KNOWLEDGE_VERSION`, a recomputed `ACTIVE_KNOWLEDGE_SOURCE_SHA256`, and a matching current fallback.
